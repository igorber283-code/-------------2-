# Исправленная сборка расписания КИТиС

## Что исправлено

- Учебный срез ИСр24-1 (16–22 ноября 2026, 18 занятий) встроен в загрузчик как резерв. Страница больше не зависит от того, успел ли GitHub Pages отдать отдельный файл расписания.
- Поддерживаются JSON-форматы с `days` как массивом или объектом дат, а также поля занятий `subject/name`, `teacher/lecturer`, `start/end` или `bells`.
- Старое пустое состояние в `localStorage` автоматически восстанавливает базовый учебный срез.
- Если выбрана другая группа, для которой в опубликованных данных нет расписания, вместо полностью пустого экрана показывается понятное пояснение.

## Установка

1. Распакуй архив в корень репозитория.
2. Замени `index.html` и папку `assets`.
3. Добавь `data/demo-schedule.js` и `data/demo-schedule.json` из архива. Существующие `data/schedule.js` и `data/schedule.json` не удаляй.
4. Сделай commit и push в `main`.
5. Открой GitHub Pages и обнови страницу жёсткой перезагрузкой: `Ctrl + F5`.

## Важно про группы

В опубликованном учебном репозитории исходно есть срез только для **ИСр24-1 за 16–22 ноября 2026 года**. Другие группы, например ИМР26-2 из сайта-примера, не появятся автоматически: для них нужно отдельно получить и подключить их данные. Выбери ИСр24-1 в списке групп, чтобы увидеть включённые в проект пары.

Пользовательские группы и личные занятия сохраняются в `localStorage` конкретного браузера. Автоматическая синхронизация между устройствами не входит в эту фронтенд-сборку.
