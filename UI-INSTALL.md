# Обновлённый интерфейс расписания КИТиС

Студенческий интерфейс для просмотра расписания занятий. Это не электронный журнал и не система учёта посещаемости.

## Что есть в интерфейсе

- Календарь недели и отдельного дня.
- Переключение между учебными группами и создание личных групп.
- Карточки занятий с предметом, преподавателем, временем и аудиторией.
- Таймер до конца текущей пары или начала следующей.
- Поиск по предмету, преподавателю и аудитории.
- Добавление и редактирование личных занятий.
- Избранная группа и экспорт расписания в `.ics`.
- Настройки оформления: светлая/тёмная тема, белая/серая либо чёрная/графитовая поверхность, семь акцентных оттенков.
- Сохранение созданных групп, расписания и оформления в `localStorage`.

## Установка

1. Распакуй архив в корень репозитория.
2. Замени `index.html`.
3. Добавь папку `assets` и файлы `data/demo-schedule.js`, `data/demo-schedule.json`.
4. Не удаляй оригинальные `data/schedule.js` и `data/schedule.json`: страница использует их как основной источник и обращается к demo-файлам только как к резервным.
5. Сделай commit и push в ветку `main`.
6. В GitHub открой **Settings → Pages** и проверь публикацию из `main` / `/root`.

## Локальный запуск

Можно открыть `index.html` через Live Server в VS Code. Для корректной загрузки JSON лучше использовать локальный HTTP-сервер, а не `file://`.

## Хранение данных

Созданные группы, индивидуальные занятия, избранная группа и настройки темы хранятся в браузере на текущем устройстве. Серверной синхронизации и авторизации в этом фронтенде нет.

## Демо-время

Параметр `?now=2026-11-18T10:30` позволяет проверить таймер на фиксированном времени, не меняя системные часы.
